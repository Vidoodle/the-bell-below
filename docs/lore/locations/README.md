# Locations

These documents record the physical layout, history, and current condition of playable places. A location may host several scenes over the course of a run; scenes describe situations that occur there rather than additional pieces of geography.

- [The Drowned Stair](drowned-stair.md) — the sealed approach from inhabited Grayhaven into the flooded cathedral close.
- [The Cathedral Close](cathedral-close.md) — the flooded courtyard and surrounding precinct outside the cathedral.
