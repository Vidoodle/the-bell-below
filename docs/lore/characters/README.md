# Characters

These documents record the histories, knowledge, relationships, and personal stakes of the playable protagonists.

- [Seren Holt](seren-holt.md) — the former captain who helped carry out and conceal the cathedral sacrifice.
- [Veyra Sable](veyra-sable.md) — the relic thief exploiting the cathedral's first opening in forty years.
- [Brother Cael](brother-cael.md) — the excommunicated archivist seeking proof that the church falsified the miracle.
- [Dame Riona Voss](riona-voss.md) — the council's appointed Bell-Warden and a true believer in Grayhaven's institutions.
